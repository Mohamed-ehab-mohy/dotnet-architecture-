نظرة عامة على المعمارية Architecture Overview

▼

المشروع مبني على Clean Architecture (المعمارية النظيفة) والتي تفصل الكود إلى 4 طبقات رئيسية. كل طبقة تعتمد فقط على ما هو داخلها — مبدأ Dependency Inversion.

🌐 Client
→
🎯 Presentation
API / Controllers
→
📋 Application
CQRS / MediatR
→
🗄️ Infrastructure
EF Core / DB
↔
💡 Domain
Entities / Rules
💡 Domain Layer

الطبقة الداخلية — كيانات الأعمال، القواعد، القيم، الاستثناءات. لا تعتمد على أي مكتبة خارجية.

📋 Application Layer

طبقة حالات الاستخدام — أوامر CQRS، استعلامات، تحقق، خرائط. تعتمد فقط على Domain.

🗄️ Infrastructure Layer

طبقة البنية التحتية — قاعدة البيانات، Identity، الخدمات الخارجية (إيميل، تخزين، دفع).

🎯 Presentation Layer

طبقة العرض — API controllers, middlewares, filters. تستقبل الطلبات وتوجهها للـ Application.

تدفق البيانات Data Flow

▼

📥 مثال: إنشاء منتج جديد (CreateProduct)

1. POST /api/products ← JSON body
→ ProductsController.Create(CreateProductDto)
→ MediatR sends CreateProductCommand
→ ValidationBehaviour ← FluentValidation
→ LoggingBehaviour ← ILogger
→ CreateProductCommandHandler
→ IRepository<Product>.AddAsync(product)
→ ApplicationDbContext → PostgreSQL
← Result<int>.Success(productId)
← 201 Created { id: productId }

📤 مثال: جلب المنتجات (GetProducts)

1. GET /api/products
→ ProductsController.GetAll()
→ MediatR sends GetProductsQuery
→ GetProductsQueryHandler
→ Repository<Product>.GetAllAsync()
→ AutoMapper: Product → ProductDto
← IReadOnlyList<ProductDto>
← 200 OK [{ products }]
تم إنشاء هذا التوثيق تلقائياً من تحليل كامل لمشروع .NET Clean Architecture — جميع الحقوق للمشروع الأصلي
